# DIGIT_CLASSIFIER
# Handwritten Digit Classification using Neural Network

This project is a handwritten digit image classification system developed using Python and Scikit-learn. The model predicts handwritten digits from 0 to 9 using a neural network approach.

## Technologies Used
- Python
- Jupyter Notebook
- Scikit-learn
- Matplotlib

## Dataset
Digits Dataset from Scikit-learn

## Features
- Image classification using neural network
- Model training and testing
- Accuracy evaluation
- Digit prediction
- Saved trained model

## Model Used
MLPClassifier (Multi-Layer Perceptron)

## Accuracy
The model achieved approximately 95% to 98% accuracy.

## How to Run
1. Open Jupyter Notebook
2. Run all cells step-by-step
3. The model will train automatically
4. Accuracy and predictions will be displayed

## Output
- Predicted handwritten digits
- Accuracy score
- Saved model file

## Conclusion
This project demonstrates handwritten digit recognition using a neural network model with Python and Scikit-learn.
